# Release 0.1.48

## User Ask

The user asked to commit this round's related changes and push a release, and to confirm the Codex TOML config was switched back to connecting to the live `open-computer-use`, not pointing at a dev build.

## Changes This Round

- **[Version bump]**: Uniformly bumped macOS / Linux / Windows runtime, plugin manifest, smoke suite, tests, and the reverse-engineering helper version to `0.1.48`.
- **[Release notes]**: Updated the user-facing release notes, explaining that this version fixes the issue where a complex window screenshot being too large caused Codex history events to degrade into a JSON text preview.
- **[Config check]**: Confirmed the local machine's Codex config for the `open-computer-use` MCP server uses the live command `open-computer-use mcp`, not pointing at a local dev binary.

## Design Intent

This round's fix already affects macOS runtime behavior in the public npm package, and the user explicitly asked to release, so it followed the release guide as a patch release. The version source of truth remains the plugin manifest, with all helper tools' and tests' version strings synced accordingly, to avoid a mismatch between the tag and the npm staging package version.
