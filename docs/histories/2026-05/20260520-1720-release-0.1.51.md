# Release 0.1.51

## Background

The permission onboarding overlay fix has been merged into `main`; a new plugin and CLI version needs to be released so that globally installed users get the `PermissionDiagnostics.current()` permission-completion-state fix.

## Main Changes

- Synced the plugin manifest, Swift version source, smoke fixture, Linux/Windows CLI, computer-use helper CLI, and README example versions to `0.1.51`.
- Added a `0.1.51` entry to the feature release notes, stating that the macOS permission onboarding overlay no longer keeps showing after completion.
- Prepared to create a `v0.1.51` annotated tag based on the merged `main`, triggering the GitHub release workflow.
