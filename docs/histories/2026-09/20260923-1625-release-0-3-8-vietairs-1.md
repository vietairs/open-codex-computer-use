### 🧠 Design Intent (Why)
`v0.3.7-vietairs.1` never reached npm: its release run failed at the npm step
because the fork has no npm auth in CI. Notarization landed after that tag. A new
version keeps the published tarballs traceable to one tagged commit. The #17
release note describes notarization as a capability that needs credentials,
because the CI-built GitHub Release artifacts are still not notarized. Only the
locally published npm packages carry the stapled app.
