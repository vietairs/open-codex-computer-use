# Release 0.3.9-vietairs.1

## Summary

Release close-out for `0.3.9-vietairs.1`, shipping the opt-in remote jev backend for `decide_next_action` (#21).

## Changes

- Bumped every version site from `0.3.8-vietairs.1` to `0.3.9-vietairs.1`: plugin manifest, Swift version constant,
  smoke suite, Linux and Windows Go binaries, the computer-use CLI and its README, and `SECURITY.md`.
- Added `docs/releases/github/v0.3.9-vietairs.1.md` and marked the 2026-09-28 feature-release row as released.

## Notes

- As with `0.3.8-vietairs.1`, the npm packages are built and notarized locally and published from a real terminal
  (npm 2FA is a passkey); the tag's CI publish step skips versions that already exist.
- The remote backend has not been exercised against a live HTTPS endpoint yet: the jev engine it targets currently
  listens on loopback over plain http.
