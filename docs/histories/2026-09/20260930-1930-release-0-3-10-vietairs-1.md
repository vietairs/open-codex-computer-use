# Release 0.3.10-vietairs.1

## Summary

Release close-out for `0.3.10-vietairs.1`, shipping the per-call latency work and batched actions (#23) and the fast macOS channels: `find_elements` and the opt-in scripting channels (#25).

## Changes

- Bumped every version site from `0.3.9-vietairs.1` to `0.3.10-vietairs.1`: plugin manifest, Swift version constant,
  smoke suite, Linux and Windows Go binaries, the computer-use CLI and its README, and `SECURITY.md`.
- Added `docs/releases/github/v0.3.10-vietairs.1.md` and added a 2026-09-30 feature-release row marked as released.

## Notes

- As with `0.3.9-vietairs.1`, the npm packages are built and notarized locally and published from a real terminal
  (npm 2FA is a passkey); the tag's CI publish step skips versions that already exist.
- The scripting channels are off unless `OPEN_COMPUTER_USE_ENABLE_SCRIPTING=1` is set in the relay's own launch
  environment; a default install exposes only the always-on `find_elements` addition.
