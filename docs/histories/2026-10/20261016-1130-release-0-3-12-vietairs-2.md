# Release 0.3.12-vietairs.2

## Summary

Release close-out for `0.3.12-vietairs.2`, shipping the stale-npm-version publish fix, the proxy call-file and inline JSON handling, the `doctor` lookup-error fix, `key_method=sky_key`, and the covered and other-Space window support.

## Changes

- Bumped every version site from `0.3.12-vietairs.1` to `0.3.12-vietairs.2`: plugin manifest, Swift version constant, smoke suite, Linux and Windows Go binaries, the computer-use CLI and its README, and `SECURITY.md`.
- Added `docs/releases/github/v0.3.12-vietairs.2.md` and a feature-release row marked as released.

## Notes

- The npm packages are built and notarized locally and published from a real terminal (npm 2FA is a passkey); this is a prerelease version, so the publish uses `--tag latest`.
- A window on another Desktop is readable but `sky_click` refuses it, because accessibility does not list such windows and cannot confirm they are not minimized.
