| 2026-09-06 | macOS secondary action | The agent can now reliably close a tab through Safari's exposed `close tab` secondary action, without triggering a different action due to internal actions being filtered out. | The macOS renderer now displays AppKit custom-action descriptors of the form `Name:close tab ...` as short names; the executor performs equivalent short-name matching against that same filtered set of raw actions and rejects ambiguous matches; when a short name collides with another raw action, the full descriptor is kept, to avoid mistakenly executing a different raw action with the same name. |
| 2026-09-06 | macOS app-name resolution | When targeting an app like Safari by name, the real application is now matched first, so a same-named background helper no longer steals the match. | Matching is now tiered: regular app name, regular app executable, background app name, background executable; ordering within a tier is unchanged, and bundle identifier and safety-filter rules are unchanged. |
| 2026-09-01 | Embedded App Agent socket isolation | A host that embeds OCU no longer contends with the user's global OCU instance over the same App Agent socket, so one instance won't accidentally kill or replace the other. | Released `0.3.3`: for a host that explicitly configures a namespace, generate a deterministic, short socket filename that doesn't leak the original value; hosts without a configured namespace keep using the old path for compatibility. |
