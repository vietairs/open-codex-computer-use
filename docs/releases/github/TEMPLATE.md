## Downloading the macOS app

A browser download of the app zip is quarantined by macOS. If the first launch is blocked, open System Settings > Privacy & Security and choose Open Anyway, or run `xattr -dr com.apple.quarantine "Open Computer Use.app"` on the unzipped app.
