## What's Changed

* macOS actions are faster. Action results are now text-only by default, so the window is captured only when you pass `include_screenshot` or the accessibility tree comes back empty. The visual cursor takes at most 0.3s to travel, and accessibility attributes are read in one round trip per element. A new `perform_actions` tool runs a short sequence of actions in one call: it validates every step first, stops at the first failure, and returns one line per step plus a single final state. (#23)
* A new read-only `find_elements` tool searches a window's accessibility tree without rendering the whole tree, and returns index rows that work with click, `set_value`, scroll, and `perform_secondary_action`. It is always on. (#25)
* Opt-in, off-by-default scripting channels for macOS: set `OPEN_COMPUTER_USE_ENABLE_SCRIPTING=1` in the relay's launch environment to add `run_script`, `get_scripting_dictionary`, `open_url`, `list_shortcuts`, and `run_shortcut`. Scripts run in a confined process behind a policy filter, and every script-channel request is written to an owner-only audit log. (#25)
