## What's Changed

* The shared app agent no longer crashes when an application reports a NaN or infinite accessibility coordinate. That crash used to close the MCP connection of every Claude and Codex session at once ("Connection closed"). (#29)
* An MCP proxy now survives the agent going away: the call in flight gets an error saying it was not retried, and the next call reconnects. A relaunch after a crash starts with lock-screen control off. (#29)
* Choosing Quit in the menu bar now keeps computer use stopped, including the scripting tools, until a new MCP host session starts. (#29)
