* Added `open-computer-use doctor --json` for a read-only permission query, `ocu config` for persistent screenshot settings with JPG output, and a faster `perform_actions` that skips the per-step read-back wait. (#31, #34, #35)
* Fixed Linux `press_key` named keys and modifiers, and Windows no longer returns degenerate screenshots. (#32, #33)
* Tag releases now publish direct-download assets (app zip, CLI archives, checksums, manifest) to the GitHub Release. (#36)
