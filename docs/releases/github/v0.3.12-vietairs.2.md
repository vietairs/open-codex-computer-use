## What's Changed

* Added `key_method=sky_key`, which types and presses keys in a window that is behind other windows or not frontmost, without moving the cursor or changing focus. (#41)
* Windows you have read with `get_app_state` keep rendering when you cover them or switch Desktop, and a window on another Desktop can be read with a screenshot. `sky_click` works on covered windows. (#42)
* The proxy now reads call files itself and sends the JSON inline, `doctor` keeps a permission lookup error as unknown, and the release publish step treats an already-staged npm version as published. (#38, #39, #40)

## Downloading the macOS app

A browser download of the app zip is quarantined by macOS. If the first launch is blocked, open System Settings > Privacy & Security and choose Open Anyway, or run `xattr -dr com.apple.quarantine "Open Computer Use.app"` on the unzipped app.
