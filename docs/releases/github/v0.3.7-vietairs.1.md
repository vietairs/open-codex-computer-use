## What's Changed

* Add a compact actionable view to `get_app_state`, which returns only the elements an agent can act on instead of the full accessibility tree, cutting the tokens a single state read costs.
* Make the fork installable and auditable under its own identity: scoped `@vietairs/*` npm package names, fork-accurate READMEs, real governance contacts, and four CI gate workflows covering docs, hygiene, action pinning and dependency auditing.
* Close a supply-chain gap where the Go vulnerability scan skipped the two modules whose binaries ship in the npm tarballs, and raise the release toolchain so those binaries no longer carry three call-reachable standard-library advisories.
