## What's Changed

* Release builds can now notarize and staple `Open Computer Use.app` when a maintainer configures notary credentials. The `@vietairs` npm packages for this release carry a notarized, stapled app. (#17)
* Add the experimental, opt-in `decide_next_action` tool: it asks a small local model you run yourself (a `llama-server` sidecar) which operation and element best fit a goal on the current screen, and returns ranked probabilities. It only advises; the host agent still verifies and acts. It is off by default because it has not yet met its accuracy targets, and appears only when the host sets `OPEN_COMPUTER_USE_DECISION_MODEL_URL`. (#18)
* Translate the remaining Chinese documentation to English. (#16)
