## What's Changed

* Notarize and staple the `Open Computer Use.app` bundle during release builds whenever notary credentials are available, so Gatekeeper accepts the downloaded app without a quarantine override. (#17)
* Add the experimental, opt-in `decide_next_action` tool: it asks a small local model you run yourself (a `llama-server` sidecar) which operation and element best fit a goal on the current screen, and returns ranked probabilities. It only advises; the host agent still verifies and acts. The tool appears only when the host sets `OPEN_COMPUTER_USE_DECISION_MODEL_URL`. (#18)
* Translate the remaining Chinese documentation to English. (#16)
