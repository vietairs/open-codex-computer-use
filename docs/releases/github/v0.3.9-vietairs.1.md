## What's Changed

* `decide_next_action` can now use a remote, OpenAI-compatible vLLM "jev" engine over HTTPS with a bearer key, as an alternative to the local `llama-server` sidecar. It stays advisory and off by default. The remote host, model, and key are read only from a private, user-owned `remote-backend.json` file, and per-call settings can only switch the backend on. Each call sends the goal and up to 52 screen rows to the host you configure. (#21)
