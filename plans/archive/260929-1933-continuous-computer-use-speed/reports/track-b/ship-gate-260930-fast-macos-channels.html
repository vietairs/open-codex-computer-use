1. TL;DR

This branch adds faster ways for an agent to drive macOS apps than reading the full screen tree:

  • find_elements, a lean breadth-first search that finds one control in about 0.02s where get_app_state takes 0.88s on Mail.
  • An opt-in, off-by-default run_script AppleScript channel with a deny filter, a confined child process and an audit log.
  • get_scripting_dictionary, which reads sdef files and never launches an app.
  • open_url, which opens in the background with blocked handlers, and list_shortcuts / run_shortcut.
  • A router that passes MCP traffic through untouched when the flag is off.

3. Intuition

  • Flag off (default): the server behaves as before, plus find_elements (11 tools). The router forwards every line without parsing it.
  • Flag on (OPEN_COMPUTER_USE_ENABLE_SCRIPTING=1): the router intercepts the local tools (16 tools) and runs them in the MCP process rather than the app agent. Each script is filtered, logged to scripts.log (mode 600) and run in a confined osascript child with a timeout.
  • find_elements reads each node once and walks level by level, so toolbar buttons are found in a few dozen nodes. Deep content can be cut off at 1200 nodes (truncated=true); pass a larger max_nodes or use get_app_state. The hit indices work in click and perform_actions until the next refresh.

4. Blast radius

  • Every MCP entry path now goes through LocalChannelRouter: relay (MacOSAppAgentProxy), direct (OpenComputerUseMain) and MCPAppRuntime. With the flag off, bytes are forwarded as-is. Live, relay and direct gave equal parsed JSON; only the key order differs between processes.
  • Tool count goes from 10 to 11 with the flag off, and to 16 with it on. Hosts with narrow allow lists should add find_elements.
  • Server instructions are 1795 characters in the worst case, under the 2048 host limit. The advisor cascade guide moved into decide_next_action's description.
  • Security residuals (documented): the filter adds friction and is not a boundary. A killed relay does not stop an Apple Event already inside the target app. Script text is logged. The phase 08 red team and the post-rebase delta review left no Critical or High findings open.
  • Nothing suspicious was found embedded in the diff or the commit messages.
